# 本編 章構成プラン

## 方針
- 既存の分岐シナリオから正規ルート（壁に頭打ち→眠いんだ→高圧洗浄機探す）を軸に一本化
- 物語プロット・各人の背景と真実・設定資料に完全準拠
- バッドエンドは本編には含めない（既存ファイルに残す）
- 一人称視点、乾いたユーモア、短い文、システムログの挿入
- **全体で60,000～80,000字を目標とする**

---

## テーマ・物語のコア

### 中心テーマ
**「記憶と時間の流れによる自己の不安定さを描き、それでもなお人を愛することを選ぶ」**

- 記憶を失い、自己が曖昧になっても、行動の根幹は変わらない
- 繰り返しの中で摩耗した感情と、それでも残る「誰かのために」という衝動
- 「大切な人」が誰かは最後まで明確にならない。それでも「会いたい」という願いそのものが愛の形である
- **分からないまま、隣にいることを選ぶ。それが答え。**

### サブテーマ
- **不完全さの肯定**: EXORはORなしでは論理的に「何も残らない」が、それでも存在している。不完全なまま存在していい
- **外部者の視点**: 主人公だけがループの外にいる。「おかしい」と言える者が変化をもたらす
- **記憶媒体としての愛**: 記憶は消えても、誰かのためにした行動の痕跡は残る

### 回路論的裏付け（→ 詳細は 設定/テーマ深化設定.md）
- **回路はリセットされても、入力があれば動く**。入力＝隣にいる誰か。回路が動くこと＝愛すること
- **XORの対称性**：「大切な人」が特定できないのはバグではなくXOR回路の性質。対象より「異なる誰かがそこにいる」行為が真を出力する
- **NOTの逆説**：執着すると失い、手放すと守れる。帽子の交換は否定回路に「失ってもいい」入力を与え、反転により「失わない」を出力させる行為
- **閉回路の発振**：ORの不在（世界が不完全なため未実装）により世界が受容力を失い、不完全な出力を繰り返しフィードバックする＝ループの回路論的本質
- **フィードバック切断**：手帳を「見ない」＝出力を入力に戻さない＝発振を止める

### 読者に伝えたいこと
- 物語前半：「この町、何か変だ」という違和感と好奇心
- 物語中盤：「この子たちは何のためにこんなに必死なんだ」という切なさ
- 物語後半：「覚えていないのに、それでも動く」という愛の形への感動
- 物語全体を通して：退廃的で乾いた、でもどこか温かい空気

## 「破綻した美少女ゲーム」の演出設計

### 基本構造
この物語は「美少女ゲームの個別ルートが意図的に壊された」メタ構造を持つ。キャラクターたちがEXOR君の願いを叶えるため、自分たちの個人ルートをへし折り繋ぎ合わせた結果、物語は以下のように破綻する：

### 段階的な崩壊

| 段階 | 章 | 状態 | 読者の体感 |
|---|---|---|---|
| 正常 | 1-3章 | 一人ずつ出会う。普通のギャルゲ的展開 | 「ああ、キャラ紹介パートね」 |
| 微不和 | 4-5章 | 出会いのタイミングが不自然に短期間に集中 | 「ちょっと展開早くない？」 |
| 侵食 | 6章 | 複数キャラのイベントがにじみ出す。A3手帳にB4 NOTの筆跡が混じる等 | 「何かがおかしい」 |
| 競合 | 7章前半 | 同時刻に複数キャラと過ごした記憶が発生 | 「物理的に不可能だ」 |
| 崩壊 | 7章後半 | ルートが完全に合流。全キャラが同時に同じシーンに登場 | 「これはバグ？いや、彼女たちが望んだこと」 |
| 統合 | 8章 | 全員が見送り、二人+ORでトンネルへ。ルートの結末 | 「全ルートが一つの結末に向かっていた」 |

### システムログとの連動
- 1-3章：ログは穏やか。「起動完了」「新規デバイス追加」程度
- 4-5章：「スケジュール衝突」「イベント順序変更」の警告
- 6章：「整合性チェック警告」「状態不確定」
- 7章：「イベントシーケンス失敗」「ロールバック抑制」「ルート統合処理中」のエラー頻発
- 8章：「最終タスク実行中」「外部入力をトリガーとして処理を再開」
- 9章：「全タスク完了」「お疲れ様でした」

### 演出上の注意
- **ルート崩壊はバグではなく愛**: 彼女たちはルートを犠牲にしてでもEXOR君を導きたかった。その必死さが「破綻」として表出する
- **主人公だけが気づく**: EXOR君は無垢だから気づかない。主人公が外部者だからこそ「おかしい」と感じる
- **読者を騙してから明かす**: 前半は普通のギャルゲとして読ませ、中盤の違和感を経て、後半に真実を読者と主人公が同時に理解する構造

## NOTの否定の力 ― メカニクス

### 基本原理
NOTが否定（疑い・不信・拒絶）を抱くと、その対象が世界から否定される。NOT回路の論理反転。

### 因果チェーン
```
NOTが「EXOR君は覚えていないかもしれない」と思った
  → EXOR君は本当に忘れた
NOTが傷ついて距離を置いた  
  → EXOR君の記憶がさらに欠落
NOTが信じられなかった
  → ORの存在が世界から否定された？（最大の帰結）
```

### 作中での表出（章ごと）
| 章 | 演出 | 種類 |
|---|---|---|
| 4章 | 髪留めの話題にNOTが「知らない」と否定 → 深追いを遮断 | 小規模否定 |
| 4章 | 高圧洗浄機：NOTが「ない」と言わなかった → 見つかった？ | 否定の不在 |
| 6章 | NOTが帽子を渡す＝否定を手放す。初めて肯定する瞬間 | 転換点 |
| 7章 | EXOR君がNOTを覚えていない事実の直面。NOTの否定が現実化した証拠 | 顕在化 |
| 8章 | 全員の「肯定」（見送り）がNOTの否定を上回る。否定の力が無効化 | 回収 |

### 演出上の注意
- NOTの否定の力は**直接的に説明しない**。パターンとして読者が気づく形にする
- NOT自身は「口に出すと否定される」ことを**恐れている**。だから寡黙
- 「…覚えていないかもしれないけど」（4章、聞こえるか聞こえないかの声）が最重要セリフ

## キャラクターアーク概要

### EXOR君：「足りない」→「足りてる」
- 全編を通じて変わらない行動規則（明るい・積極的・粘り強い）
- しかし「足りない」感覚が徐々に強くなっていく（2章→6章→7章で頂点）
- 8章トンネルで「足りてる気がする」へ。成長ではなく**充足**
- EXOR君は世界の構造に一切気づかない。だからこそ純粋な感情の器として機能

### NOT：「否定」→「肯定」
- 4章では全てを否定する（「知らない」「別に」）
- 6章で帽子を主人公に渡す＝初めての肯定（手放す勇気）
- 7章で否定の力が顕在化。EXOR君に覚えていないと言われる痛み
- 8章の見送りで「行ってきなよ」＝最大の肯定。EXOR君を送り出す
- NOTのアークは**否定ではなく肯定を選ぶ**物語

### AND：「不完全への苛立ち」→「許容」
- 5章で「記録が矛盾している」と苛立つ。完璧主義の表出
- 6章で「彼女の名前を呼んで」のメモを発見。自分が書いた記憶がない困惑
- 7章で「分かりません。なぜ私がこんなに必死なのか」と吐露
- 9章「完全ではないですが、許容範囲です」＝AND回路が「不完全な入力でも出力する」へ変化

### 半加算シスターズ：「半分」→「それでも全力」
- 3章で無邪気に登場。「半分」の自覚はまだ薄い
- 6章「わたしたち、足りないよね」＝半加算器として全加算器になれない自覚
- 7章「2人だけじゃ完全じゃないの」＝喪失感の頂点
- 8-9章「がんばれなの！」＝足りなくても応援できる。半分でも全力

### FF：「観測者」→「当事者」
- 5章初登場。神出鬼没。距離を取ろうとする
- 6章でノートを見せる。支離滅裂でも伝えようとする
- 7章「まだ、いないからね」＝知っている最後の一欠片を漏らす
- 8章「面白いデータが取れそうだ」でも笑っている＝観測者から当事者へ。最後のループだから
- 9章「最後のページ、もう書く必要ないな」＝記録の終了。物語の外に出る

### 比較：「守護者」→「託す者」
- 5章で神社を守っている。「知らない方がいい」と拒む
- ふと「また同じ春ね」と漏らす＝ループの残滓
- 8章で封鎖された道を開ける＝守護から解放へ。ORの髪留めを主人公に託す
- 「お願い。今度こそ」＝焦りの記憶は失われているが、使命感だけが残っている

### 主人公（入力）：「空っぽ」→「隣にいる」
- 1章で空っぽの家、空っぽの心。「いってきます」に返事がない
- 2-4章で面倒くさがりながらも人と関わり始める
- 5-6章で違和感に気づき始める。記憶媒体を集め始める
- 7章で彼女たちの「理由のない確信」に心を動かされる
- 8章で全てを理解し、EXOR君を連れてトンネルへ。自ら動く
- 9章「いってきます」の意味が変わる。帰る場所＝待っている人がいる

## OR独白ターン ― 設計

### 概要
システムログとは別の「もう一つの声」。ORが世界の外側から語りかける独白。名前は一切明かさず、誰の声かも示さない。初読では「なんだこれ？ ポエム？」程度。2周目で「全部ORの声だった」と気づく構造。

### システムログとの対比

| | システムログ | OR独白 |
|---|---|---|
| 言語 | プログラム用語 | 音楽用語 |
| 視点 | 世界（システム）の報告 | 消された個人の独白 |
| 温度 | 冷たい・機械的 | 温かい・寂しい |
| 書式 | `[日付:] [ログレベル:]` | 地の文とも違う短い散文 |
| 意味 | 世界の状態 | ORの感情・記憶 |
| 読者の印象 | 「この世界はプログラムだ」 | 「誰かが見ている」 |

### 書式ルール
```
――

（ここにOR独白。3～6行の短い散文。音楽用語を自然に織り込む）

――
```
- 二重ダッシュ `――` で囲む。システムログの `[` `]` とも地の文とも違う
- 一人称は使わない。「わたし」「僕」等の自称なし。ただ語る（**例外**: #5で渇望の高まりにより初めて「わたしのパート」が漏れる）
- 最初は環境音・感覚の描写だけ。徐々に「誰か」に語りかける口調へ
- 音楽用語は説明しない。文脈で伝わる程度に自然に使う

### 各章配置と変化

| 章 | タイミング | 音楽用語 | 内容 | 読者の印象 |
|---|---|---|---|---|
| 1章 | システムログ直後 | なし | ただ見ている。繰り返しを。淡々と | 「何だこの一文？」程度 |
| 2章 | EXOR登場後の章末 | なし | あの子の声を知っている。でも届かない | 「また出た。誰だろう」 |
| 4章 | NOT退場後 | 変奏（1語だけ） | 否定されるたび薄くなる。でもまだ聴こえる | 「少し音楽っぽい？ 気のせいかな」 |
| 6章 | EXOR「足りない」の後 | フェルマータ、間奏 | 時間が引き延ばされている。待っている。ずっと | 「この声、待ってる人がいる」 |
| 7章 | ルート崩壊の中 | 輪舞(ロンド)、全休止 | 全員の声が聞こえる。でも自分の音だけない。名前を呼ばれたい | 「この声の主は…いない人？」 |
| 8章 | トンネル内部 | コーダ、ダ・カーポ→否定 | 終わりの始まり。もう最初には戻らない。でも今、隣にいる | 「OR…！」（読者が気づく瞬間） |
| 9章 | 最後の朝の直前 | 通奏低音 | 音楽用語を使わない最後の独白。ただ「おはよう」 | 「泣く」 |

### 独白の変化アーク
1. **観察**（1章）: 繰り返しを見ている。自分が何かも分からない。ただ見ている
2. **記憶**（2章）: あの子の声を知っている。でも名前が出てこない。手が届かない
3. **浸食**（4章）: 否定されるたび自分が薄くなる。初めて「音」という感覚が混じる
4. **停滞**（6章）: 待っている。何を？ 誰を？ 分からないけど待っている
5. **渇望**（7章）: 全員の声が聞こえる。自分の音だけない。名前がほしい
6. **邂逅**（8章）: 足音が二つ。近づいてくる。温かい。もう繰り返さなくていい
7. **沈黙**（9章）: 音楽用語を手放す。ただの言葉で「おはよう」

### 演出上の注意
- **絶対にORとは書かない**。「声」「独白」等の名義もつけない。ただ `――` で始まり `――` で終わる
- **他のキャラはこの独白に気づかない**。読者だけが読むメタレイヤー
- **音楽用語は段階的に**。#1-#2は音楽用語ゼロ。#3で1語。#4から本格化。#5がピーク。#7で再びゼロ。読者が「あれ、この声って音楽っぽい？」と気づくのは#4あたりが理想
- **8章で初めて、トンネル内でEXOR君の「ここ、知ってる気がする」「誰かが、待ってる」とOR独白が呼応する**。二つのレイヤーが重なる瞬間
