# Logic-Gate 分岐の作法（構造ガイド）

分岐の**中身の文章**は必ず `logic-gate-prose` の文体で書く。このスキルは**分岐の骨格**（どこに何種類の選択肢を置くか・書式・バッドの型・配線）を担当する。原典は `シナリオ/`（＝作法の出どころ）、運用版は `本編/`。判断に迷ったら `シナリオ/顔合わせのターン/分岐構造図.md`、`本編/選択肢規約.md`、`本編/分岐/分岐マップ.md` を参照。

## 大原則：骨格は一本道

本編＝**グランドルート（正典の一本道）**。選択肢は「選択肢付きVN」への味付けであって、**物語の背骨は分岐させない**。最終エンド（24章）へは必ず一本で繋がる。個別ヒロインルートはグランドクリア後の別枠。

## 選択肢は二種類だけ

### ① 再合流フレーバー選択肢 `◇選択◇`（大半はこれ）
本線を分岐させない。**反応・情景・情報の解像度・好感の機微**だけが変わり、数行ですぐ本線へ戻る。1章に **2〜3個**。

書式（本編・インライン）:
```
◇選択◇
① （踏み込む／触れる／付き合う 寄り）
② （距離を取る／流す／放っておく 寄り）

―①―
（その選択の短い地の文。数行）
―②―
（その選択の短い地の文。数行）
―合流―
（本線へ戻る一文）
```

- **性格軸は全章一貫**：①＝踏み込む・触れる・付き合う ／ ②＝距離を取る・流す・放っておく。
- 入力（俺）は基本②寄りの人間。**②を選んでも“間違い”ではない**（面倒くさがりの彼らしさが出るだけ）。①だと伏線の種に一歩触れられることがある。
- どちらを選んでも**後続の伏線・記憶媒体（帽子・手帳・ノート・貝殻・写真等）の配置を壊さない**。種は必ず本線側に置く。

### ② バッドエンド分岐 `◆分岐◆【重要】`（重要局面のみ・例外）
本当に分岐する。正しい選択＝本線継続、間違い＝**バッドエンドへ退避**（本線に戻さない）。

書式（分岐点）:
```
◆分岐◆【重要】
① （正しい選択 → 本線継続）
② （間違い → バッドエンド：本編/バッドエンド/バッド_第N章_タイトル.txt）

―①―
（正しい側の地の文。本線へ続ける）
―②―
（間違い側への導入を一行だけ置き、バッド本文ファイルへ送る）
```
※既存章では①が正しい側だが、23章のように**②が正しい**配置もある。番号ではなく「席を守る／誰も捨てない」側が正解と判断する。

## バッドエンドの唯一の型：ループ回帰

バッドの本質は一貫して **「誰かを選ばなかった／見捨てた／未来を勝手に確定させた」**（＝逆順VNの「誰も捨てない」テーマの裏返し）。読後感は**破滅ではなく“静かなやり直し”**。世界がプログラムなので、失敗すると誰にも届かないまま最初に戻る。

バッド本文ファイルの構成（`本編/バッドエンド/バッド_第N章_タイトル.txt`）:

1. `【BAD END：タイトル】` で始める。
2. **選んだ間違いの所作**を短く描く。説明せず、画と所作だけ。
3. `…／……／………` で時間を飛ばす。
4. **喪失が“静かに”効く情景**。誰かが消えている／席が空いている／音だけが残る。直接の情の吐露は「その背中が、とても寂しそうに見えた」程度が上限（→ prose skill 原則4）。
5. `日付: … ／ ログレベル: 警告 or エラー ／ 詳細: …`（**非ブラケット**・機械語）。「初期地点へ復帰」「再試行を待機」等でループ回帰を示す。
6. `――` で挟む **OR独白**。「また、最初から。／何度でも。」で締める定番。一人称を使わない。
7. 末尾に `【BAD END】` と **やり直し案内**：
   ```
   ――「（選んだ間違いの選択文）」を選んだあなたへ――
   （何が足りなかったかを一行）。第N章の分岐からもう一度。
   ```

見本＝`本編/バッドエンド/バッド_第2章_一人ぼっちの音.txt`（去っていく足音・削られていない壁・遠くの壁打ちの音）、`バッド_第18章_返した手.txt`（席を正しく返しても実体が伴わず再発振）。

## バッドを置く局面の選び方（中盤の集中投下）

各ヒロインに**一度ずつ「見捨てる」機会**を配るのが設計目標。EX-OR偏重を避け、中盤（黄金期〜不安期）に散らす。局面は各ヒロインの**記憶媒体・約束・見せ場**に紐づける。

| ヒロイン | 見せ場（例） | バッドの型 |
|---|---|---|
| EX-OR | 2章 壁打ち／14章 手帳の未来 | 応えない・去らせる／未来を確定させる |
| 全加算=双子/FF | 3章 見捨て／13章 観測 | 置いて先へ行く・観測をやめる |
| NOT | 4章 港／10章 浜辺の貝殻 | 帰れないものを置いていく |
| AND | 11章 指切り／12章 図書室 | 約束を断る・名前を呼ばない |
| 比較 | 5・12・22章 神社 | いってらっしゃいを返さない・見送らない |

置いたら必ず **`本編/分岐/分岐マップ.md` のツリーとバッド一覧を更新**。バッド本文ファイル名の章番号は「見せ場の章」ではなく置いた章に合わせるか、既存の命名（旧採番踏襲）に倣うか、マップ側で対応を明記する。

## 禁則（全選択肢・全バッド共通）

- 選択肢の文言・分岐テキスト・バッド本文で **「ルート」「OR」「システム／エンジン」を地の文・キャラの口に出さない。**
- バッドでも**真相を説明しない**。画と所作で「間違えた」ことだけを残す。
- 「OR」の直接言及が必要になったら、表層モチーフ **「足りない」** に置換する。
- 世界＝プログラムの示唆は**システムログ（読者専用層）だけ**に許す。本編準拠で非ブラケット書式。
- OR独白 `――` は読者専用レイヤー。**他キャラは気づかない**。

## 原典（シナリオ/）の旧書式との対応（移植時の変換表）

原典を本編へ移すときは以下に変換する:

| シナリオ原典 | 本編（運用版） |
|---|---|
| 末尾に `分岐` ＋選択肢ラベル1行ずつ | `◇選択◇`/`◆分岐◆` の記号書式 |
| 別ファイル `_バッドエンド.txt`（ツリー） | `本編/バッドエンド/バッド_第N章_◯◯.txt` に集約 |
| `[日付:…][ログレベル:…][詳細:…]` ブラケット式 | 非ブラケット `日付: … / ログレベル: … / 詳細: …` |
| `BADEND ◯◯` / `==== 【バッドエンドN】◯◯ ====` | `【BAD END】` ＋ やり直し案内 |
| `※このエンドから抜け出すには…` | `――「選択文」を選んだあなたへ――` 定型 |
| 地の文に出る「OR」直接言及 | 「足りない」へ置換 |

## チェックリスト（分岐を書いた後）
1. フレーバーは**両方**本線へ戻り、伏線配置を壊していないか？
2. バッドは**ループ回帰**（破滅でなく静かなやり直し）になっているか？
3. `◇選択◇` の①②は性格軸（踏み込む/流す）に合っているか？
4. 「ルート/OR/システム」を地上に出していないか？（→「足りない」へ）
5. システムログは非ブラケット・機械語・ループ示唆になっているか？
6. `分岐マップ.md` のツリー＋バッド一覧を更新したか？
7. 文章は `logic-gate-prose` の声で書けているか？（句の孤立・息継ぎ読点・乾いた笑いの有無）
