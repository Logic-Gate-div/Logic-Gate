# Logic-Gate 文体ガイド（作者の声）

このプロジェクトの地の文は作者本人の文体で書く。判断に迷ったら `本編/第1章_起動.txt`・`第4章_NOT.txt`・`第7章_黄金の日々.txt` と `シナリオ/` を正典として参照する。

## 絶対原則（ここを外すと「別人の文章」になる）

### 1. 一行に「文」を置く。「フレーズ」で刻まない
反復すら一行で流す。改行は段落・文の単位で入れる。単語や句を一行に孤立させない。

- ✗（別人）:
  ```
  足が、勝手に、動いている。
  NOTと、同じだ。
  一歩。
  また、一歩。
  ```
- ○（作者の声）:
  ```
  足が勝手に動いている。NOTと同じだ。理由なんかない、体が勝手に、というやつだ。
  ```
- 正典例:「教室の窓から、山が見える。海が見える。空が見える。それ以外に何も見えない。この町はいつもそうだ。」（反復も一行で流す）

### 2. 読点は普通の文法密度。ドラマ用の細切れ読点を禁止
- ✗「あたたかい。全部、あたたかい。」「胸の、奥が、ぎゅっと、なった。」
- ○「案外きれいな色してたんだな」「痛いところを突いてきた。」
- 息継ぎ演出のための読点を入れない。読点は文法が要求するときだけ。

### 3. 乾いた大喩ユーモアを、緊迫・悲しい場面でも殺さない
これが作者の署名。誇張した比喩・自虐・人を食ったツッコミを地の文に混ぜる。
- 正典例:「黒板の字が難破して、読めるのか読めないのか紀元前から議論があるレベルだ。」
- 「誰も知り合いのいない環境で過ごしたいなら、国外逃亡より先にこちらを選ぶだろう。」
- 「家庭教師よりも少人数だ。」「消しパンよりかはましだぞ。」
- シリアスな章でも、地の文の一つは必ずこの乾いた笑いを残す。しんみりさせっぱなしにしない。

### 4. 感情は抑制。画を見せて、解釈は最大で一言
詠唱・反復で泣かせにいかない。情景に語らせ、締めに一行だけ解釈を許す。
- 正典例（バッドエンドの悲しみ）:「がん。がん。がん。／遠くから聞こえる、その音。／それは、入力を拒絶する音のようだった。」
- 直接的な情の吐露は「その背中が、とても寂しそうに見えた。」が上限。それ以上こねない。

### 5. 会話は速射。タグ最小、会話文の中で改行して溜めない
- `話者「セリフ」` 形式。「と言った」等のタグはほぼ付けない。
- 掛け合いはテンポよく畳みかける。
  ```
  EX-OR「お弁当ある?」
  入力「食パン」
  EX-OR「食パンかぁ」
  入力「悪いか。消しパンよりかはましだぞ」
  ```
- セリフ内をポエム改行で分断しない。

### 6. 内心 `(…)` は少なめ・一文で
乾いた独り言。多用して一行ずつ並べない。
- ○「(誰もいない町で、俺は何をしているんだ)」

## 固定フォーマット（変えない）
- **一人称**：入力＝俺。素っ気なく、面倒くさがりで、でも見るところは見ている観察眼。
- **システムログ**：`日付: XXXX年XX月XX日 時刻: hh:mm:ss` / `ログレベル: 情報|警告|エラー` / `詳細: …`。世界がプログラムである示唆。冷たい機械語。章末や転換に置く。
- **場面転換**：`…` → `……` → `………` の三段。
- **OR独白**：`――` で挟む短い散文。音楽用語を織り込む（変奏→通奏低音→輪舞→コーダ…と段階的に増え、最終章で消える）。一人称を使わない（規定の例外を除く）。他キャラは気づかない読者専用レイヤー。
- **登場人物**：入力(俺) / EX-OR(彼女だが少年風、明るく粘り強い、髪留め) / NOT(三角帽子、寡黙、猫的距離、否定の力) / 半加算=双子(はーちゃん・さーちゃん、「〜なの」「〜なのです」、二人同時は「「…」」) / AND(完璧主義、図書室、敬語) / FF(白衣、神出鬼没、ノート) / 比較(神社、寡黙) / エンコーダ・デコーダ(気のいい先輩、名簿)。
- **回路特性の書き方**：各キャラの論理ゲート性を「超常イベント」でなく「思考の癖・口癖」として滲ませる作法は `references/キャラ思考形態.md` を参照（三層の役割分担／比較さん・ANDが手本／NOTは古い魔法モードから修正／EX-OR・双子は要彫り込み）。ロアの正典は `各人の背景と真実.md`・`物語プロット.md`。

## 語彙・リズムの手癖
- 「〜だ」「〜のだ」の言い切り。体言止めも使うが乱発しない。
- 情景描写は必ず態度（wry attitude）を帯びる：「試しにドの鍵盤を押してみる。ぼわん、と情けない音がした。」
- 退廃・錆・色褪せの町。でも底に温度がある。
- リフレイン：「いってきます」（返事なし）、「足りない」、風を見るEX-OR、三点リーダー転換。既存のものを勝手に増やさず活かす。
