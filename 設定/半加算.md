# 半加算シスターズ（はーちゃん・さーちゃん）

## 基本情報
- 一人称: わたし
- 学年: 1年生
- 記憶媒体: **手帳**（未来が書き込まれる手帳 / 白紙に戻っていく手帳）
- この物語における立場: **ループの痕跡を最も多く残す記憶媒体の管理者**

## 性格

### 無邪気な双子
- 元気で明るく、かくれんぼが大好き
- 背が小さいことを気にしている
- 区別がつきにくい似た口調

### 「足りない」感覚
- 「2人だけじゃ足りない」という漠然とした喪失感
- 2人合わせても「ぜんりょくの全加算器」にはなれない
- しかしその意味を深くは考えない（子供だから）

### 「半分」の自覚
- 自分たちが「半分」であることを漠然と感じている
- でもそれが何の半分なのかは分からない

## 外見
- 緑色のふりふりワンピース
- そっくりだが微妙に違う双子

## 物語における役割

### 手帳の管理者
- 彼女たちの手帳には未来のことが書いてある
- 物語開始時点で紛失している
- 主人公が持っている新品の手帳と「同じもの」
- 主人公の手帳に文字が書き込まれていく / 彼女たちの手帳は白紙に戻る

### ループの痕跡
- 手帳の中に「また同じ春が来る」「彼女の影が薄れていく」等の抽象的な記述
- 巻き戻りを恐れて具体性を削ぎ落とした形で残されている
- 彼女たち自身はその意味を理解していない
- 主人公が読み解くことでループの存在が明らかになる

### 未来の不確定化
- 主人公が手帳の内容を「見ない」ことで、未来が確定されなくなる
- これが最終的にループを断ち切る鍵となる

## 口調パターン

```
「~なの」「~なのです」「~だもん」
半加算「はーちゃんは~なの」
半加算「さーちゃんは~なのです」
```

```
// 日常
半加算「かくれんぼしよ！」
半加算「いっしょにさがして！」
入力「…自分で探せ」
半加算「「えー！」」

// 「足りない」の表現
半加算「わたしたち、足りないよね」
半加算「2人だけじゃ、完全じゃないの」
（でも何が足りないかは分からない）

// 手帳について
半加算「手帳なくしちゃった」
半加算「未来のことが書いてあったのに」
半加算「でもまた書けばいいよね」
```

## 世界認知レベル: 2（漠然とした喪失感）
- 手帳に未来が書いてあることは知っているが深く考えない
- 世界の異常性には無関心（子供だから）
- 「2人だけじゃ足りない」感覚はあるが、それ以上は追求しない
- 焦っていた記憶は完全に失われている
