# AND

## 基本情報
- 一人称: 私
- 学年: 3年生
- 記憶媒体: **伝承メモ**（神社とトンネルの伝承を調査したメモ）
- この物語における立場: **情報の収集者。伝承を通じて世界の構造に迫る**

## 性格

### 真面目で完璧主義
- 両方揃わないと気が済まない
- 中途半端を許せない（AND回路＝両方の入力が揃って初めて出力）
- 論理的で理屈っぽい
- **内心では苛立つことがあっても、表面的には冷静を保つ**
- 「当然でしょう」が口癖

### 図書館の住人
- ずっと図書館にいる研究者タイプ
- 資料の欠損や矛盾に強く苛立つ
- でも本当は疲れている

### 感情を隠す
- **表面的には冷静だが、内心は感情的**
- はーちゃん（半加算）と仲良し（唯一甘くなる相手）
- 比較とは利害の一致で協力関係
- **苛立ちや困惑を表に出さず、理性的に対処しようとする**

### 母性の暴走＝殺伐とした優しさ（2026-08-21追記）
AND回路の法則「全部揃って初めてOK、一つでも欠けたら丸ごと偽」を、彼女は無意識に**人間の欠落データ**にまで適用している。誰かが「昼を抜いた」「怪我をした」「眠っていない」――目の届く範囲で一項目でも条件が欠けていると、彼女の中でその日の記録が丸ごと「偽」になる。だから彼女の世話焼きは"任意の親切"ではなく、**彼女自身の回路が成立するための必須条件**。満たされなければ彼女自身が欠けてしまう。

- **殺伐＝優しさの表現に愛想がないこと**。声を荒げない、甘い言葉を使わない、敬語のまま淡々と踏み込んでくる。「大丈夫です」と言われても「記録上そうは見えません」で押し返す。
- **母性＝相手を選ばない総量**。特定の誰かを溺愛するのではなく、視界に入った全員が対象になる。全校生徒分の塩飴・経口補水パウダー・絆創膏を"欠けている状態で誰かが倒れるのは看過できない"という理由だけで常備している。
- **怖さ＝完璧に届いてしまう精度**。頼んでもいないのに、去年のタイムも、他人の三日前の睡眠時間も、今朝の体温も記録している。見てないようで見ている、数えていないようで数えている。本人に悪気は一切ない。悪気がないことがなお怖い。
- **落とし方（否定できる一滴に留める）**：どこに物資が入っているか等、説明が過剰にオカルトへ寄りそうな部分は「…企業秘密です」で流し、断定しない。あからさまな超常はキャラに背負わせない（三層分担・システム層のみ許可）。

## 物語における役割

### 伝承の調査者
- 図書館の資料からトンネルの伝承を調べている
  - 「1人で通ると失われ、2人で通ると仲たがいし、3人で通ると――」（情報の欠損）
  - 「3人、というよりかは仲の良い複数人」が正しいと推測
- 比較さんの神社に伝わる伝承と照合している
- 核心に迫るメモ書きは伝承メモの表紙の裏に挟まっている

### 情報の不完全さへの苛立ち
- 記録が矛盾している、資料が欠けている
- AND回路として「両方揃わないと」気が済まないのに、片方が常に欠けている
- その苛立ちが主人公に対する厳しさとして表れる

### ルートの犠牲者
- かつての個人ルートを失い、物語の情報提供者として組み込まれている
- 本人はそれを覚えていないが、「何かをやり遂げなければ」という焦燥感だけが残っている

## 口調パターン

```

```

```
AND「…村の伝承を調べています」
入力「何か分かったか」
AND「私が知りうるのはこの図書館でのことだけなので」

// 苛立ち
AND「おかしいんです。記録が矛盾してる」
入力「どう矛盾してるんだ」
AND「それが…説明できないんです」

// 母性の暴走（殺伐とした優しさ）
入力「…お前、自分のことしか記録してないよな」
AND「いえ。全員分です。欠けていると、気になるので」
入力「…それただの怖い話だからな」
AND「褒め言葉として受け取っておきます」
```

- 焦っていた記憶は失われている
