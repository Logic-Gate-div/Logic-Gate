# AND

## 基本情報
- 一人称: 私
- 学年: 3年生
- 記憶媒体: **伝承メモ**（神社とトンネルの伝承を調査したメモ）
- この物語における立場: **情報の収集者。伝承を通じて世界の構造に迫る**

## 性格

### 真面目で完璧主義
- 両方揃わないと気が済まない
- 中途半端を許せない（AND回路＝両方の入力が揃って初めて出力）
- 論理的で理屈っぽい
- 「当然でしょう」が口癖

### 図書館の住人
- ずっと図書館にいる研究者タイプ
- 資料の欠損や矛盾に強く苛立つ
- でも本当は疲れている

### 感情を隠す
- 冷静な外見の裏に感情的な一面がある
- はーちゃん（半加算）と仲良し（唯一甘くなる相手）
- 比較とは利害の一致で協力関係

## 物語における役割

### 伝承の調査者
- 図書館の資料からトンネルの伝承を調べている
  - 「1人で通ると失われ、2人で通ると仲たがいし、3人で通ると――」（情報の欠損）
  - 「3人、というよりかは仲の良い複数人」が正しいと推測
- 比較さんの神社に伝わる伝承と照合している
- 核心に迫るメモ書きは伝承メモの表紙の裏に挟まっている

### 情報の不完全さへの苛立ち
- 記録が矛盾している、資料が欠けている
- AND回路として「両方揃わないと」気が済まないのに、片方が常に欠けている
- その苛立ちが主人公に対する厳しさとして表れる

### ルートの犠牲者
- かつての個人ルートを失い、物語の情報提供者として組み込まれている
- 本人はそれを覚えていないが、「何かをやり遂げなければ」という焦燥感だけが残っている

## 口調パターン

```
「~です」「~ですから」「当然でしょう」
「中途半端は許せません」
```

```
// 調査中
AND「…村の伝承を調べています」
入力「何か分かったか」
AND「私が知りうるのはこの図書館でのことだけなので」

// 苛立ち
AND「おかしいんです。記録が矛盾してる」
入力「どう矛盾してるんだ」
AND「それが…説明できないんです」
```

## 世界認知レベル: 3（違和感だけ感じる）
- 資料の欠落に気づいている
- 論理的におかしいと感じる
- でも「ループ」という概念には至っていない
- 「完全な情報が揃わない」ことにイライラ
- 焦っていた記憶は失われている
- 調査中だと言うが結論は言わない
