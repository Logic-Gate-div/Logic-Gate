# FF（フリップフロップ）

## 基本情報
- 一人称: 私（時々「あたし」に揺れる）
- 学年: 3年生
- 記憶媒体: **研究ノート**（ループの記録を断片的に書き記したノート）
- この物語における立場: **かつての観測者。しかし今は記憶を失い、ノートだけが証拠**

## 性格

### 神出鬼没
- いつの間にかそこにいる。いつの間にかいなくなる
- 予測不能な行動パターン

### 感情が摩耗している
- 繰り返しの中で感情がすり減っている
- しかしその「すり減った理由」を覚えていない
- 時に冷静、時に興奮――日によってテンションが変わる

### かつての知識の残滓
- ループを知っていた唯一の存在――だった
- 今は記憶を失い、ノートに書かれた内容を自分でも完全には理解できない
- 「これが最後のループだ」という直感だけが残っている
- 説明しようとすると支離滅裂になり、途中で諦める

## 外見
- 濃い紫の長髪、白衣
- 研究ノートを常に持っている

## 物語における役割

### ループの記録者
- ノートにはループの痕跡が抽象的に描かれている
  - 「時計の針が逆回りする」「同じ言葉を何度も聞いた気がする」
  - ページを繰るほど筆致が荒くなっていく
  - 巻き戻りを恐れて、具体的な内容は意図的に削ぎ落とされている
- このノートが、主人公がループの真実に迫るための最重要資料

### 世界を守ろうとした人
- 不安定な繰り返しを知り、思い出を切り捨ててまで世界を守ろうとした
- しかしその犠牲も記憶も失われている
- ノートの荒れた筆致だけが、彼女がどれだけ必死だったかを物語る

### 「最後」の直感
- 記憶を失っても「これが最後だ」という感覚だけが残っている
- その直感に従って行動するが、なぜそう感じるのか説明できない
- 主人公に「面白いね」「予想外だ」と言うが、何が予想外なのか自分でも分からない

## 口調パターン

```
「…何度目かな」「また、か」
「面白いね」「予想外だ。再計算が必要だな」
（疲れた口調と、興味津々な口調が混在。）
```

```
// 登場
FF「…何度目かな」
入力「何が」
FF「…ううん、独り言」

// ノートを見せる
FF「これ、読める？」
入力「…字が荒すぎて読めない」
FF「そう。私にも読めないの」
FF「でも、私が書いたの。確かに」

// 支離滅裂になる
FF「あのね、この町は――」
FF「いや、違う。そうじゃなくて」
FF「…ごめん。うまく言えない」
```

## 世界認知レベル: 5→1（認知していたが記憶を失った）
- かつてはループを完全に認知していた（レベル5）
- 何度も繰り返しを経験し、研究ノートに記録を残していた
- しかし今は記憶を失い、ノートの内容すら完全には理解できない
- 「最後のループ」という直感だけが残っている
- 焦っていた記憶は失われているが、ノートの筆致がその痕跡を留めている
