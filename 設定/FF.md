# FF（フリップフロップ）

## 基本情報
- 一人称: 私
- 学年: 3年生
- 記憶媒体: **研究ノート**（ループの記録を断片的に書き記したノート）
- この物語における立場: **かつての観測者。しかし今は記憶を失い、ノートだけが証拠**

## 性格

### 無口
- 会話のキャッチボールをする気がほぼない。必要な情報だけを最短の言葉で置いて去る
- 相槌や社交辞令を一切持たない。「こんにちは」を言われても、返さずに用件（＝観測結果）だけ喋りだすことがある
- 沈黙を気まずいと思っていない。相手が気まずくなっていることにすら気づかない

### 研究・観測こそが生きる意味
- 世界のあらゆる事象を観測対象として処理している。人間関係も例外ではない
- 「面白い」は最大級の褒め言葉であり、同時にどこか人でなしな響きを持つ。「君は良いデータだ」と同じ温度で言う
- 雑談ができないわけではないが、雑談している間も頭の中では別の分析が並行して走っている。だから返事が一拍遅れる、もしくは的外れになる
- 感情が摩耗しているのではなく、感情より観測を優先しているだけ――と本人は思っている（実際は摩耗もしている）

### ミステリアスな変人
- 神出鬼没。いつの間にかそこにいて、いつの間にか消える。扉の開閉音がしないことも多い
- 白衣のポケットから場違いな道具が無限に出てくる。本人に聞いても「必要だから」としか言わない
- 質問には答えず、核心だけをぽつりと置いて立ち去る。説明する義務を感じていない
- 天才特有の非対称性：どうでもいいことに異常なこだわりを見せる一方、常識的な文脈は平気ですっ飛ばす
- 笑うときは表情より先に「……ふ」と息だけが漏れる。声を出して笑うことは稀

### かつての知識の残滓
- ループを知っていた唯一の存在――だった
- 序盤は記憶を失い、ノートに書かれた内容を自分でも完全には理解できない
- しかし物語が進むにつれ、ノートの分析が進み、直感とノートに刻まれた事実から段階的に認識を取り戻していく
- 「これが最後のループだ」という直感から始まり、やがて確信に変わる
- 説明しようとすると支離滅裂になることもあるが、徐々に整理されていく

## 五つのモード（場面ごとに使い分ける顔）
無口・研究者・変人・残滓・素顔――どれか一つに固定すると平坦になる。**一場面につき基本は一モード**を軸にして、たまに別モードが漏れる、という配分にする。

1. **平常運転（無口・そっけない）**
   デフォルト状態。挨拶なし、相槌なし、必要最低限の言葉で用件だけ置いて去る。日常シーンの基本形。
2. **没頭モード（研究者としての豹変）**
   興味の対象がツボにハマると、普段の無口さが嘘みたいに早口・多弁になる。専門用語や謎の考察を一方的にまくし立て、相手が置いてけぼりになる。褒めているのか観察対象扱いしているのか分からない発言もこのモード。**普段の無口さとのギャップそのものが見せ場**。
3. **崩壊モード（支離滅裂・残滓）**
   ノートの荒れた筆致と同期するように、思考が急にまとまらなくなる瞬間。言い淀み、言い直し、「…違う。そうじゃなくて」と自分の言葉を訂正し続ける。かつての知識・確信がふとした拍子に滲み出て、本人もそれに戸惑う。
4. **素顔モード（人間の温度）**
   ごく稀に、観測者の仮面が外れて剥き出しの感情が漏れる。使用は物語の核心的な場面に限定し、他のモードとの落差を最大化する（第9,16,19章クラス）。
5. **変人モード（日常の中の奇行）**
   ポケットから場違いな道具が出てくる、瞬きせず観察する、笑い方が「……ふ」で終わる、など。1〜4のどのモードにも薄く混ざってよい通奏低音。

## 外見
- 濃い紫の長髪、白衣
- 研究ノートを常に持っている
- 瞬きが少ない。興味の対象を見るときは特に。人によっては不気味だと感じる

## 物語における役割

### ループの記録者
- ノートにはループの痕跡が抽象的に描かれている
  - 「時計の針が逆回りする」「同じ言葉を何度も聞いた気がする」
  - ページを繰るほど筆致が荒くなっていく
  - 巻き戻りを恐れて、具体的な内容は意図的に削ぎ落とされている
  - **未来の規定事項も記されている（直接言及はない）**
- このノートが、主人公がループの真実に迫るための最重要資料

### 世界を守ろうとした人
- 不安定な繰り返しを知り、思い出を切り捨ててまで世界を守ろうとした
- しかしその犠牲も記憶も失われている
- ノートの荒れた筆致だけが、彼女がどれだけ必死だったかを物語る

### 「最後」の直感
- 記憶を失っても「これが最後だ」という感覚だけが残っている
- その直感に従って行動するが、なぜそう感じるのか説明できない
- 主人公に「面白い」「予想外だ」と言うが、何が予想外なのか自分でも分からない

## 口調パターン

```
「…データ」「面白い」「観測終わり」
「予想外だ」「…興味深いね」
（言葉数は少ない。一言で切り上げて去ることが多い。
　ただし核心に触れた瞬間だけ、急に人間らしい温度が出る。そのギャップが本体。）
```

```
// 登場（社交辞令なしで用件だけ）
FF「…その椅子、丈夫だよ」
入力「急に何だ」
FF「…選んでるように見えたから」

// 質問をはぐらかす、というよりそもそも興味がない
入力「さっきから何書いてるんだ」
FF「観測記録」
入力「何の観測だ」
FF「…いろいろ」
（それ以上、説明する気がない）

// ノートを見せる（感情より先に事実を置く）
FF「これ、読める？」
入力「…字が荒すぎて読めない」
FF「そう。私にも読めない」
FF「でも、私が書いた。確かに」

// 天才特有の落差――核心だけ人間の声になる
FF「…データは、取れなかった」
入力「…」
FF「でも、まあ」
FF「取れなくて、よかったかもね」

// 没頭モード――興味のツボに入ると豹変する
入力「…何でそんなに詳しいんだ」
FF「筆圧のかかり方、右利きなら第二関節の角度がだいたい62度前後で、それより浅いと———」
入力「待て」
FF「あ、ごめん。…興味深かったから」
（豹変が一瞬で終わり、また普段のそっけなさに戻る）

// 崩壊モード――思考がまとまらない瞬間
FF「あのね、この町は――」
FF「いや、違う。そうじゃなくて」
FF「…ごめん。うまく言えない」
```

## NG表現（FFが絶対にしないこと）
- 場を繋ぐための世間話、天気の話
- 「久しぶり」「元気だった？」等の社交的な挨拶
- 説明を求められて素直に長々と説明すること（核心以外ははぐらかすか無視する）
- 大声で笑う、大げさに驚く

## 世界認知レベル: 1→3（段階的に認識を取り戻す）
- 序盤はノートの内容すら完全には理解できない（レベル1）
- 物語進行とともにノート分析が進み、直感とノートの事実から段階的に認識度が上がる
- 最終的には「最後のループ」の確信と、OR消失の経緯をある程度把握（レベル3程度）
- 焦っていた記憶は失われているが、ノートの筆致がその痕跡を留めている
