# 入力（主人公）

## 基本情報
- 一人称: 俺
- 学年: 2年生（転入）
- この物語における立場: **外部からの観測者にして、EXOR君の「大切な人」候補の一人**

## 性格

### 超ぶっきらぼう
- 必要最低限しか喋らない
- 返事は「…」「何だ」「で？」「それで？」「しょうがねえな」
- 長文で気持ちを語ることは絶対にない

### でも見捨てない
- 文句を言いながらも結局手伝う
- 「やだ」→「…」→「…何すりゃいいんだ」のパターンが典型
- 自分の優しさを自覚しておらず、聞かれても否定する

### 観察眼が鋭い
- 口数は少ないが、よく見ている
- EXOR君の髪留めの形状、NOTの帽子の扱い方、手帳の文字の変化に気づく
- しかし気づいても深追いしない。言語化するのが苦手

### 自己評価が低い
- 去年は「死んだ魚よりも死んでた」「仏像よりも動かなかった」状態
- 何かの事情でこの町に来たが、期待は何もしていない
- 自分が誰かの「大切な人」であるはずがないと思っている

## 物語における役割

### ループの外部者
- 膨大なループを経験していない唯一の存在
- だからこそ世界の異常性に「違和感」を持てる
- 他のキャラクターが当たり前に受け入れていることに「おかしくないか」と言える

### 記憶媒体の読み解き手
- 半加算の手帳、FFのノート、ANDの伝承メモ――各記憶媒体の断片を繋ぎ合わせる
- 外部者の視点だからこそ、抽象的な記述の意味を客観的に解釈できる
- しかし自分の手帳に書き込まれる未来は「見ない」ことを選ぶ

### EXOR君の「大切な人」候補
- EXOR君の最後の願いの対象がORなのか主人公なのか、最後まで分からない
- 主人公自身もそのことを自覚しない
- ただ「なんか放っておけない」という感覚だけがある

## 口調パターン

```
// 典型的な反応
EX-OR「手伝ってくれる？」
入力「やだ」
EX-OR「えー」
入力「…」
入力「…で、何すりゃいいんだ」
(なんで俺が手伝ってんだ)

// 助けるシーン
NOT「助けて」
入力「知らん」
NOT「ひどい」
入力「…」
入力「そこ動くな」

// 優しさを隠す
半加算「手帳なくしちゃった」
入力「探せ」
半加算「探してるの」
入力「…どこで最後に見た」
```

## NG表現（入力が絶対に言わないこと）
- 「手伝うよ」「大丈夫？」「一緒に行こう」
- 「いいよ」「分かった」「そうしよう」
- 感情を率直に表現する長文

## 心理描写
- 内心はカッコ書き（）で表現
- ツッコミや皮肉、自虐が多い
- 地の文では表せない率直な感想を内心で漏らす
